# Parakeet CoreML as an alternative speech provider

Local Dictation keeps Voxtral (Python / MLX WebSocket server) as the default speech runtime and adds Parakeet TDT 0.6B v3 CoreML as a selectable alternative. Parakeet runs in-process through the FluidAudio Swift SDK: models load and unload with the same ready / dormant lifecycle as the supervised server, and the existing dictation session protocol is preserved by buffering microphone PCM and batch-transcribing on finalize. This avoids a second Python stack for CoreML, reuses FluidAudio’s ANE-optimized pipeline, and costs a provider switch plus non-streaming partials for the Parakeet path. We rejected replacing Voxtral outright and rejected a Python CoreML bridge because both either remove a working realtime path or add a fragile interop layer without improving latency.
