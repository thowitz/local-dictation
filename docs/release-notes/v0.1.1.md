Bug-fix release. The speech runtime no longer lets its GPU memory grow without bound during a long-running session. Requires an **Apple Silicon** Mac and **macOS 15+**.

## What's fixed

- **Runaway memory growth (~14 GB).** The app holds a single long-lived connection to the speech runtime across every dictation, but the runtime only released MLX's Metal buffer-reuse pool when that connection closed. With no ceiling on the pool, freed-but-retained GPU buffers accumulated for the life of the connection — pushing the runtime's memory footprint to ~14 GB (visible in Activity Monitor, though not in `ps`) until idle-unload killed the process. The runtime now caps its buffer pool at startup and releases it after each finalized utterance, so the footprint holds flat at the model floor (~3.4 GB) regardless of how long you dictate.

## Install

1. Download `LocalDictation-v0.1.1.zip` (and `LocalDictation-v0.1.1.zip.sha256`) from this release.
2. Verify the checksum in the download directory:
   ```bash
   shasum -a 256 -c LocalDictation-v0.1.1.zip.sha256
   ```
3. Unzip with Finder (double-click) or:
   ```bash
   ditto -x -k LocalDictation-v0.1.1.zip .
   ```
4. Drag `LocalDictation.app` into `/Applications` (or `ditto LocalDictation.app /Applications/LocalDictation.app`).
5. Open the app. On first launch, the **Setup Checklist** walks Microphone, Accessibility, Input Monitoring, and mic-key remap.

## Self-signed, not notarized

This build is signed with a **self-signed** certificate named `Local Dictation Signing` and is **not notarized**. Gatekeeper will block the first launch of a downloaded copy.

- **Right-click** `LocalDictation.app` → **Open** → **Open Anyway**, or
- Clear quarantine: `xattr -dr com.apple.quarantine /Applications/LocalDictation.app`

Do **not** disable Gatekeeper globally.

**Why self-signed?** Launch at Login needs a *stable* signature. The package uses a designated requirement anchored to the certificate's Common Name, so Launch-at-Login registrations stay valid across updates signed with any cert of that name. Downloaders do not need to re-sign anything — this is a persistence mechanism, not a security boundary.

## Prefer to sign it yourself?

If you'd rather not run a binary carrying someone else's certificate, build from source:

```bash
git clone https://github.com/omcdowell/local-dictation.git
cd local-dictation
make signing-identity && make package && make package-check
# then install dist/LocalDictation.app
```

See the README's [Persistent Launch at Login](https://github.com/omcdowell/local-dictation#persistent-launch-at-login-one-time-signing-setup) section for details.

For development setup, permissions, config, and troubleshooting, see the [README](https://github.com/omcdowell/local-dictation#readme).
