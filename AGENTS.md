# Repository guidance

## Agent skills

### Issue tracker

Issues and PRDs are tracked in `omcdowell/local-dictation` GitHub Issues; implementation plans in `docs/plans/` supplement their linked issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage uses the canonical `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix` labels; `blocked` is an auxiliary dependency label. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository using root `CONTEXT.md` and `docs/adr/`, created lazily as domain decisions emerge. See `docs/agents/domain.md`.
